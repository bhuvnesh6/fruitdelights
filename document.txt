================================================================================
                              PROJECT DESCRIPTION
================================================================================

Fruite Delight CRM is a comprehensive Customer Relationship Management (CRM) 
system designed specifically for fruit and related businesses. It provides a 
robust platform to manage customer relationships, sales operations, deliveries, 
invoicing, and business inquiries in a streamlined and efficient manner.

The application is built with Flask (lightweight Python web framework) and uses 
MongoDB as the database backend, ensuring scalability and flexibility for 
business operations.

================================================================================
                              KEY FEATURES
================================================================================

1. USER MANAGEMENT & AUTHENTICATION
   - Secure user registration and login system
   - Password hashing using industry-standard encryption (Werkzeug)
   - Session management for secure user sessions
   - Role-based access control (RBAC) with different user roles
   - Admin account creation and management

2. TEAM MANAGEMENT
   - Create and manage teams within the organization
   - Team collaboration features
   - Role-based permissions for different team members

3. SALES PLANNING & MANAGEMENT
   - Create and manage sales plans
   - Track sales activities and metrics
   - Plan-based organization of customer interactions

4. CUSTOMER INQUIRY MANAGEMENT
   - Capture and track customer inquiries
   - Inquiry status management
   - Follow-up tracking and management

5. DELIVERY MANAGEMENT
   - Track delivery operations
   - Manage delivery schedules and logistics
   - Delivery status tracking

6. INVOICE & BILLING SYSTEM
   - Generate professional invoices
   - Invoice management and tracking
   - Email invoice distribution to customers (via email service)
   - Invoice status monitoring

7. EMAIL COMMUNICATION
   - Automated invoice sending via email
   - Customer communication through email integration
   - Uses Resend email service for reliable delivery

8. ROLE-BASED ACCESS CONTROL
   - Different permission levels for different user roles
   - Secure endpoint protection
   - Role-specific feature access

================================================================================
                          HOW TO GET STARTED
================================================================================

1. INSTALLATION:
   - Clone the repository
   - Install dependencies: pip install -r requirements.txt
   - Create .env file with configuration:
     * MONGO_URI (MongoDB connection string)
     * DB_NAME (Database name)
     * SECRET_KEY (Flask secret key)
     * Email service credentials (for Resend)

2. DATABASE SETUP:
   - Ensure MongoDB is running and accessible
   - Run create_admin.py to create initial admin user
   - Collections will be created automatically on first use

3. RUN THE APPLICATION:
   - Development: python app.py
   - Production: gunicorn app:app

4. DOCKER DEPLOYMENT:
   - Build: docker build -t fruite-delight-crm .
   - Run: docker run -p 5000:5000 fruite-delight-crm
